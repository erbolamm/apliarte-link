¿Qué es ApliArte Link?

Instálalo en dos o más ordenadores conectados a la misma red WiFi. Mueve el ratón al borde de la pantalla y el cursor "salta" al siguiente PC. El teclado y el ratón te siguen automáticamente.

🖱️

Cambio explícito

Transferí el control con un comando configurable (triple clic o tecla).

⌨️

TCP + TLS

Conexión cifrada y confiable. Sin paquetes perdidos.

⚡

MessagePack binario

8× más rápido que JSON. Input en tiempo real sin latencia.

👥

Privacidad por amigos

Solo los equipos de tus amigos te ven. Nadie más en la red.

🎨

App nativa Flutter

Interfaz moderna en macOS y Windows. Tema claro y oscuro.

🔍

Descubrimiento automático

Tus equipos se encuentran solos en la red local.

Descargar

🍎 macOS Apple Silicon + Intel — M1 al M4, MacBook, iMac
Abrí Terminal y pegá esto — descarga, descomprime, quita el bloqueo y lanza la app
cd ~/Downloads && curl -L https://apliarte-link.web.app/downloads/apliarte-link-macos-app.zip -o apliarte-link.zip && unzip -o apliarte-link.zip && xattr -dr com.apple.quarantine apliarte_link.app && open apliarte_link.app
🪟 Windows x64 — Windows 10 / 11
Abrí CMD o PowerShell como administrador y pegá esto — descarga, descomprime, desbloquea y lanza la app
powershell -NoProfile -ExecutionPolicy Bypass -Command "$d=Join-Path $env:USERPROFILE 'Downloads'; Set-Location $d; Stop-Process -Name apliarte_link,apliarte-link -ErrorAction SilentlyContinue; Invoke-WebRequest -Uri 'https://apliarte-link.web.app/downloads/apliarte-link-windows-app.zip' -OutFile 'apliarte-link.zip'; if (Test-Path '.\apliarte-link') { Remove-Item '.\apliarte-link' -Recurse -Force }; Expand-Archive '.\apliarte-link.zip' -DestinationPath '.\apliarte-link' -Force; Get-ChildItem '.\apliarte-link' -Recurse | Unblock-File; Start-Process '.\apliarte-link\apliarte_link.exe'"

Si no tenés PowerShell: descargá el ZIP, descomprimilo y abrí apliarte_link.exe. Si SmartScreen aparece: Más información → Ejecutar de todas formas.

🐧 Linux x64 — app completa (Flutter + daemon embebido, X11/Wayland vía uinput)
Abrí la terminal y pegá esto — descarga, descomprime y lanza la app
mkdir -p ~/Downloads && cd ~/Downloads && curl -L https://apliarte-link.web.app/downloads/apliarte-link-linux-app.zip -o apliarte-link-app.zip && unzip -o apliarte-link-app.zip -d apliarte-link-app && cd apliarte-link-app/bundle && ./apliarte_link

Requisito: acceso a /dev/uinput — sudo usermod -a -G input $USER y reiniciar sesión. La app muestra los equipos conectados: haz clic para cambiar el control y configura tus comandos desde Ajustes.

🗺️ Roadmap

Lo que hay, lo que viene y lo que está en el horizonte. La lista crece según las ideas y el apoyo.

Listo

Fase 0 — MVP: daemon Rust + UI Flutter

Captura/inyección en macOS, Windows y Linux, discovery UDP, cambio por comando explícito, IPC.

Listo

Fase 1 — Protocolo confiable: TCP+TLS+MessagePack

Migración de UDP+JSON a TCP+TLS+MessagePack. Handshake de versión, keep-alive, conexiones persistentes. Tests 6/6.

Listo

Backend Linux — inyección uinput real

Dispositivo virtual uinput (X11 + Wayland), ratón/teclado/scroll con modificadores. Test de humo real superado.

Siguiente

Fase 2 — Descubrimiento privado por amigos

Registro por correo, amigos mutuos, rendezvous server. Solo te ven equipos que autorizaste.

Planificado

Fase 3 — Calidad de input: edge-switching y keymap

Transición por borde de pantalla, mapeo de layouts de teclado (ES↔US↔LATAM), multi-monitor.

Planificado

Fase 4 — Portapapeles, archivos y notificaciones

Clipboard sharing, arrastrar y soltar archivos, notificaciones push entre amigos.

Idea

Fase 5 — App móvil y distribución

App compañera iOS/Android, firma de binarios (Developer ID, Authenticode), auto-update, instaladores .dmg/.msi/.deb/.AppImage.

Planes futuros

Estos planes no están activos. Son la dirección si el apoyo no fuera suficiente para mantener la app gratuita. Los enseñamos por transparencia, de buena fe.
